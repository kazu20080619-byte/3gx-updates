# ゲームだけの名前は <ゲーム>\読みのなおし.txt にも書ける（こちらより先に使う）

# ■ 書きかえたあと
#   3GX を作り直さずに使う: python 3GX\共通\build.py 真打 --menu-only
#     → SD の /luma/plugins/benri/yomi.txt に入る。ゲームを起動しなおすと、さがすときに使われる
