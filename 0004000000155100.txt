# ---- 場所の目印 ----
# お金などの入れ物（セーブのセクション 09 と同じ並び）。お金は +14
#   目印は、入れ物の頭の「43 2D B6 AF」と、そのすぐ前の 74 36 7F 00（v3136 の vtable 0x7F3674）。
#   前の目印（43 2D B6 AF 00 00 00 00 A6 89 A4 D4 …）は、始めたばかりのセーブでは +8 が 0 なので見つからなかった
@find MONEYSEC | 08600000-08A00000 | 74 36 7F 00 43 2D B6 AF | +4
# 仲間の妖怪の一覧（1匹 0xC4 バイト・392 匹ぶん）。お金の入れ物の 0x1502C 手前
#   +00 妖怪の ID（0 なら空き）・+3C 個体値（5つ）・+4B レベル・+52 名前を変えられないしるし
#   +5C ステータス（HP・ちから・ようりょく・まもり・すばやさ）
@ptr YOKAI | {MONEYSEC} | -1502C
